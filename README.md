# Habit Quest App

## Overview
Habit Quest is a gamified habit tracker that helps users create and maintain habits while leveling up their character. The application features character stats, a stats dashboard, and a habit creation form.

## Project Structure
```
habit-quest-app
├── public
│   └── index.html       # Main HTML structure of the application
├── src
│   └── server.js       # Node.js server to serve static files
├── package.json         # npm configuration file
└── README.md            # Project documentation
```

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm (Node Package Manager)

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   cd habit-quest-app
   ```

2. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
1. Start the server:
   ```
   npm start
   ```

2. Open your browser and navigate to `http://localhost:3000` to access the application.

### Features
- Create and manage habits
- Track daily, weekly, and monthly completion rates
- Export and import habit data using CSV files
- Level up your character based on habit completion
